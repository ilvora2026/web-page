Create a login account

The system automatically generates a strong initial password and emails it to this registered address. The password remains valid until changed at first login.

Account creation safeguards

  • Role is assigned by the authenticated server, never by the employee.
  • Branch assignment is validated against active D1 branch records.
  • Branch Admin / HR can only create Employee and Attendance Marker accounts for their own branch.
  • Executive and Administrator accounts are not created through this screen.
  • New accounts require a password change at first sign-in.
  • Every account creation is written to the audit log.

Provision an Administrator account

This separate function is available only to the authenticated Managing Director. It creates an organisation-wide Administrator login and does not change existing role permissions.

The account will be assigned the Administrator role and organisation-wide scope. The new Administrator must change the temporary password at first sign-in. Share credentials privately.

Provisioning safeguards

  • Server verifies the current session is Managing Director.
  • Role is fixed by the server as Administrator; it cannot be selected or changed in the request.
  • Branch assignment is fixed to organisation-wide (no branch ID).
  • Strong temporary password is required and password change is enforced at first sign-in.
  • Duplicate usernames are rejected by the database.
  • Creation is recorded in the audit log.

Role permission boundaries

Account status meanings

Active Account may sign in.

Suspended Sign-in blocked and existing sessions revoked.

Deactivated Sign-in blocked and existing sessions revoked. Employee records are retained.

Deactivation must only follow approved employment action and must not delete payroll, attendance, leave, medical or statutory records.
